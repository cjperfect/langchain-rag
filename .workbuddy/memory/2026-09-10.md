# 2026-09-10

## 修复 `pnpm dev:frontend` 启动报错：Export useThreadListItemRuntime doesn't exist

**原因**：`apps/frontend/package.json` 对 `@assistant-ui/react` 使用 `"latest"`，实际装到 0.15.18。
v0.15 移除了 v0.12 起标记 deprecated 的旧 context hooks，其中包括 `useThreadListItemRuntime`。
官方迁移映射（https://assistant-ui.com/docs/migrations/v0-15）：
- `useThreadListItemRuntime()` → `useAui().threadListItem`（v0.15 起 scope accessor 是属性，不再当函数调用）
- `useThreadListItem(selector)` → `useAuiState((s) => s.threadListItem)`

**改动文件**：
1. `apps/frontend/components/assistant-ui/thread-list.tsx`
   - 导入 `useThreadListItemRuntime` → `useAui`
   - `ThreadListItem`：`runtime.getState().title` → `useAuiState((s) => s.threadListItem.title)`；`runtime.rename()` → `aui.threadListItem.rename()`
   - `ThreadListItemMore`：`runtime.delete()` → `aui.threadListItem.delete()`
2. `apps/frontend/adapters/remote-thread-list.adapter.tsx`
   - `HistoryProvider`：`runtime.getState().remoteId` → `useAuiState((s) => s.threadListItem.remoteId) ?? ""`

**验证**：`tsc --noEmit` 无相关报错；dev server 上 `/` 与 `/knowledge` 均 HTTP 200，会话列表正常渲染。

**遗留（与本次无关的既有类型错误）**：
`app/knowledge/_components/create-document-dialog.tsx:114` 与 `document-viewer.tsx:87` 使用了 tiptap `Editor.getMarkdown`（需 `@tiptap/core` 提供，当前类型定义缺失）。

## 项目约定备忘
- assistant-ui 相关依赖锁定为 `"latest"`，升级会带来破坏性变更，升级后需对照官方 migration guide 检查旧 hook。
